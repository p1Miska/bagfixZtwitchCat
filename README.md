Phantom Twitch Cats
Клиентский Fabric-мод для Minecraft Java: зрители Twitch тратят Channel Points на награду«Призови кота» — и рядом со стримером появляется фантомный кот с ником зрителя.

Кот существует только на клиенте стримера: сервер о нём ничего не знает.Мод работает на любых серверах (vanilla / Paper / Purpur) без установки чего-либо на сервер.

⚠️ Перед первой сборкой (Minecraft 26.1.2)
Откройте https://fabricmc.net/develop, выберите целевую версию Minecraft.
Впишите точные номера в gradle.properties: minecraft_version, yarn_mappings,loader_version, fabric_version (и версию fabric-loom в build.gradle,modmenu_version — из https://maven.terraformersmc.com/releases/com/terraformersmc/modmenu/).
Соберите: gradlew build. Если конкретные имена API не совпадают — в MIGRATION.mdперечислены все чувствительные места и готовые замены.
В репозиторий текстом нельзя положить бинарный gradle-wrapper.jar:скопируйте gradlew, gradlew.bat и gradle/wrapper/gradle-wrapper.jarиз официального шаблона https://github.com/FabricMC/fabric-example-mod(или выполните gradle wrapper при установленном Gradle).

Возможности
Призывается через Channel Point Reward, полностью клиентский.
Ванильная модель кота: все 11 окрасов, котята, ошейник, анимации, мяуканье.
Имя зрителя над котом, постоянно видимое (отключается в настройках).
Следует за стримером, гуляет, смотрит по сторонам, прыгает, садится/встаёт.
Не уходит дальше настраиваемой дистанции (по умолчанию 50 блоков) —при превышении телепортируется в безопасное место рядом с игроком.
Ограниченное время жизни (по умолчанию 5 минут), у каждого кота свой таймер.
Много котов одновременно, лимит настраивается.
Один активный кот на зрителя: повторная покупка возвращает Channel Points.
Простой выбор окраса текстом награды: чер, бел, рыж, сер, сиам, мини чер…
Прямая интеграция с Twitch (OAuth + EventSub WebSocket) — без внешних сервисов.
Автопереподключение, дедупликация redemption (в т.ч. между запусками).
Таймеры котов переживают смену сервера/мира/респавн.

Установка
Fabric Loader для вашей версии Minecraft + Fabric API (обязательно).
Mod Menu (необязательно, но удобно — кнопка настроек).
Положите jar в папку mods.
Настройка Twitch (один раз, ~5 минут)
Зайдите на https://dev.twitch.tv/console/apps/create:
Name — любое; Category — Application Integration;
OAuth Redirect URLs — добавьте http://localhost:16734;
Create.
Скопируйте Client ID, нажмите New Secret и скопируйте Client Secret.
В игре: Mod Menu → Phantom Twitch Cats → Config(или команда /phantomcat config).
Вкладка Twitch: вставьте Client ID и Client Secret → нажмите«Авторизовать Twitch» → в открывшемся браузере разрешите доступ.Статус должен стать «Twitch: подключён ✓».
Создайте на канале награду за баллы канала, например «Призови кота».Важно: не включайте у награды «Пропускать очередь запросов» —иначе Twitch не позволит вернуть баллы при повторной покупке.
В настройках мода нажмите «Загрузить награды из Twitch» и выберите награду(мод запомнит её ID — переименование награды ничего не сломает).
Описание для награды (пример для зрителей)
Напиши окрас: чер / бел / рыж / сер / сиам / брит / калико / перс / рэгд / джел / всечер / таббиДля котёнка добавь «мини»: «чер мини» или «мини чер».Ничего не написал — будет случайный окрас.
Команды зрителей (текст в активации награды)
Текст	Результат
чер	чёрный кот
ЧЕР МИНИ	маленький чёрный котёнок
мини бел	маленький белый котёнок
мини	котёнок случайного окраса
(пусто)	кот случайного окраса
непонятно	кот случайного окраса (неизвестный окрас)
Регистр не важен. Список команд/алиасов расширяется в конфиге.

Команды стримера (клиентские, на любом сервере)
/phantomcat spawn <ник> [окрас/мини…]   — тестовый призыв (напр.: /phantomcat spawn TestUser чер мини)/phantomcat remove <ник>                — удалить кота конкретного зрителя/phantomcat removeall                   — удалить всех котов/phantomcat list                        — список котов, окрасы, состояние, остаток времени/phantomcat reload                      — перезагрузить конфиг/phantomcat config                      — открыть настройки/phantomcat twitch status|connect|disconnect
Как это работает
Фантомные коты — реальные объекты CatEntity с собственным клиентским EntityType,но они никогда не добавляются в мир → ни одного пакета на сервер, другие игроки их не видят.
Поведение (следование, посадка, прыжки, телепорт в безопасную точку) — собственныйклиентский «мозг»; рендер — ванильным рендерером котов после обычных сущностей.
Twitch: OAuth Authorization Code (браузер → http://localhost:16734), токены хранятсялокально и автоматически обновляются; события приходят через EventSub WebSocket напрямую в мод.
Каждая активация имеет уникальный redemption ID — дубликаты игнорируются всегда.
Успешный призыв → redemption помечается FULFILLED; повторная покупка / лимит котов /стример не в игре → CANCELED (баллы возвращаются зрителю, если это позволяет Twitch).
Конфигурация
config/phantom-twitch-cats.json — время жизни, дистанция, лимит, алиасы окрасов и т.д.config/phantom-twitch-cats-auth.json — токены Twitch (не публикуйте этот файл!).config/phantom-twitch-cats-redemptions.json — обработанные redemption ID.

Устранение неполадок
«Адрес уже используется» при авторизации — измените порт в настройках модаи добавьте такой же redirect URL в приложение Twitch.
Награда не срабатывает — проверьте статус (/phantomcat twitch status), что выбранаправильная награда (лучше по ID через «Загрузить награды»).
401 / «подписка отозвана» — «Выйти из Twitch», затем авторизуйтесь заново.
Не возвращаются баллы — Twitch позволяет менять только незавершённые redemption:отключите у награды «Пропускать очередь запросов».
